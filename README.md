# A-Maze-ing

## Description

A-Maze-ing is a Python project developed as part of the 42 curriculum. Its goal is to create a maze generator capable of generating, solving, displaying and exporting mazes.

The program reads a configuration file, generates a random maze according to the selected parameters, calculates the shortest path between the entrance and the exit, and writes the result to an output file.

The maze is represented as a grid of cells, with each cell using a 4-bit integer to keep track of its North, East, South and West walls.

The project implements two maze generation modes:

- **Perfect maze:** A maze with no loops, where there is exactly one possible path between any two accessible cells.
- **Imperfect maze:** A maze with multiple possible routes, designed to avoid dead ends and provide alternative paths.

The generated maze also includes the 42 pattern, represented by fully closed cells.

## Features

- Random maze generation.
- Perfect and imperfect maze generation modes.
- Randomized Depth-First Search (DFS) algorithm.
- Dead-end detection and removal.
- Special handling of the 42 pattern.
- Shortest path calculation using Breadth-First Search (BFS).
- 4-bit wall representation.
- Configuration file parsing.
- Maze export using hexadecimal wall encoding.
- Maze visualization.
- Reusable maze generation module.

## Configuration

The project uses a plain text configuration file to define the maze generation parameters.

Each configuration option must follow the `KEY=VALUE` format, with one option per line. Lines starting with `#` are treated as comments.

| Key | Description | Example |
|---|---|---|

## Maze Generation Algorithms

### Perfect Maze — Recursive Backtracking (DFS)

Perfect mazes are generated using the Recursive Backtracking algorithm, implemented iteratively with a stack.

The algorithm follows these steps:

1. Select a random starting cell.
2. Mark the cell as visited and push it onto the stack.
3. Inspect the current cell and find its unvisited neighbours.
4. If unvisited neighbours exist:
   - Select one randomly.
   - Remove the wall between the current cell and the selected neighbour.
   - Mark the neighbour as visited.
   - Push the neighbour onto the stack.
5. If no unvisited neighbours exist, backtrack by popping the stack.
6. Continue until the stack is empty.

This algorithm produces a connected maze without cycles, ensuring a unique path between any two accessible cells.

### Imperfect Maze

The imperfect maze is generated by first creating a perfect maze using Recursive Backtracking.

Additional connections are then opened by removing selected walls between neighbouring cells. This introduces cycles and creates alternative routes.

The generation process also includes dead-end detection and removal:

1. Identify cells with only one open connection.
2. Exclude the two inaccessible cells inside the curves of the 42 pattern.
3. Select a closed wall adjacent to a dead end.
4. Remove the wall to create an additional connection.
5. Recalculate the dead ends and repeat the process.

The four corner cells are also opened to ensure they have connections to the interior of the maze.

The goal is to produce a fully connected board with multiple independent routes and as few dead ends as possible.

### Why These Algorithms?

Recursive Backtracking was chosen because it is straightforward to implement, produces connected mazes, and naturally creates a perfect maze.

Using a stack avoids the need for recursive function calls and makes the generation process easier to control.

The imperfect maze builds upon the perfect maze algorithm, allowing additional paths to be introduced without having to implement an entirely different generation algorithm.

## Maze Solving Algorithm

The shortest path between the entrance and the exit is calculated using **Breadth-First Search (BFS)**.

BFS explores the maze level by level using a queue (FIFO — First In, First Out).

The algorithm:

1. Starts at the entrance.
2. Adds the starting cell to the queue.
3. Retrieves the next cell from the queue.
4. Checks its four possible neighbours.
5. Ignores neighbours that are outside the grid, separated by a wall, or already visited.
6. Adds valid neighbours to the queue and records their parent cell.
7. Stops when the exit is reached.
8. Reconstructs the path by following the recorded parent cells backwards.

BFS guarantees the shortest path when every movement has the same cost.

The resulting solution is represented as a sequence of direction letters:

- `N` — North
- `E` — East
- `S` — South
- `W` — West

## Wall Representation

Each cell is represented by a 4-bit integer. Every bit corresponds to one of its four walls.

| Direction | Constant | Bit value |
|---|---|---|
| North | `N` | `0001` |
| East | `E` | `0010` |
| South | `S` | `0100` |
| West | `W` | `1000` |

A bit set to `1` means that the wall is closed. A bit set to `0` means that the wall is open.

The four directions are combined using bitwise OR:

```python
ALL = N | E | S | W
```

This gives `1111`, meaning that all four walls are initially closed.

Walls are opened using bitwise AND and NOT:

```python
matrix[y][x] &= ~direction
```

When a wall is removed, the corresponding wall of the neighbouring cell is also removed to keep the maze consistent.

## Output File Format

The generated maze is exported using one hexadecimal character per cell.

Each row of the maze is written on a separate line.

After the maze representation, an empty line is followed by:

1. The entrance coordinates.
2. The exit coordinates.
3. The shortest path from entrance to exit, represented using `N`, `E`, `S` and `W`.

The output file can be checked using the `maze_analyzer.py` script provided with the project subject.

## Maze Generator Reusability

The maze generation logic is organized so that it can be reused independently of the main program.

The reusable module provides a `Grid` class responsible for creating and storing the maze structure.

A basic usage example:

```python
from <module_name> import Grid

# Create a grid
grid = Grid(20, 15)

# Generate a perfect maze
grid.perfect_maze()

# Access the generated maze
maze_matrix = grid.matrix
```

To generate an imperfect maze instead:

```python
from <module_name> import Grid

grid = Grid(20, 15)
grid.imperfect_maze()

maze_matrix = grid.matrix
```

The generated structure can be accessed through the grid's matrix, while the entrance, exit and solution can be accessed through the corresponding project components.

The module is packaged separately so it can be installed and reused in future projects.

Build the package with:

```bash
make build
```
